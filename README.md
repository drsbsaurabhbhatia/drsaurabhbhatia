# Dr. Saurabh Bhatia — Sustainable Packaging Portfolio

A static portfolio ready for GitHub Pages. No build or dependency installation is required.

## Publish using the GitHub website

1. Create or open the GitHub repository where you want this portfolio.
2. Extract the ZIP on your computer. Upload the extracted files and the assets folder into the repository root. Do not upload only the ZIP.
3. Make sure index.html appears at the top level, alongside style.css, app.js and publications.js.
4. Open the repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select your source branch (usually main) and the /(root) folder, then Save.
7. When deployment finishes, use the Visit site link shown in Pages settings.

GitHub Pages availability depends on your account plan and repository visibility. A public repository works with GitHub Free. Publishing with GitHub Pages makes the website publicly accessible; create a private repository first if you only want to store the files.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit later

- index.html: biography, research areas, expertise, contact information and page structure.
- publications.js: publication entries.
- style.css: appearance and responsive layout.
- assets/packaging-portrait.webp: current portrait.

Commit changes to the publishing branch to update the live website.

## Add to Google Sites

Once GitHub Pages is active, open your Google Site and choose Pages > + > Full page embed. Paste the published GitHub Pages URL, then publish your Google Site. The exported portfolio contains no ChatGPT sign-in requirement.

## Files

The package includes the current portfolio and the assets it uses. Site-hosting configuration, access tokens, Git history and unused laboratory photos are excluded. Google Fonts loads from its online stylesheet; system font fallbacks remain available when offline.
